# 中文 AI 味语料库（人读版）

机器可读数据在 `markers.json`（stats.py 的唯一事实源），本文件解释分类与用法。
区分两类表达（P3 原则）：**领域惯例模板**（如"本文采用固定效应模型"——正常学术写法，保留）
与**机器痕迹模板**（下表——消除）。

## 高危（出现即扣分）

| 表达 | 说明 |
|------|------|
| 值得注意的是 / 需要注意的是 / 值得一提的是 | 万能插入语，AI 高频；删掉或改为直接陈述 |
| 综上所述 / 总而言之 | 机器式总结开头；结论应自然收束 |
| 众所周知 / 毋庸置疑 / 不可否认 | 空洞断言，学术写作应给出依据 |

## 中危（密度过高才是问题）

首先 / 其次 / 再次 / 最后（机械排比链）；此外 / 与此同时 / 一方面…另一方面（连接词单一化）；
具体而言 / 换句话说（元话语堆叠）。

## 语域错误

说白了 / 其实呢 / 咱们 —— 口语，学术论文禁用。

## 使用方式

- `stats.py` 按 markers.json 统计密度：≥5 处/千字 = high；≥2.5 或句长 CV<0.35 = medium。
- 修复方向见 `rewrite-techniques.md`，分节允许度见 `section-conventions.md`。
