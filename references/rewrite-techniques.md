# 保义改写技法手册

所有技法的前提：语义锁（lock.json）原样存活。改写单位是 prose block。

## 技法目录

1. **信息重排（reorder）**：调整句内成分顺序或句间顺序，不改变命题与因果方向。
2. **拆句 / 合句（split / merge）**：把均匀长句拆开、把碎片句合并，制造自然节奏。
3. **衔接多样化（connective_swap）**：此外→另外/同时/也；删掉可省的衔接词（中文常可省）。
4. **去模板（detemplate）**：删除"值得注意的是"类插入语，把信息直接并入句子。
5. **hedging 校准（hedge_fix）**：证据强→"表明/显著"；证据弱→"可能/在一定程度上"。
   只校准档位，不改方向。
6. **语域修正（register_fix）**：口语词→学术词；空洞强调→具体陈述。

## 禁止场景（每条都对应 hard-fail）

- 换数字写法（除非白名单等价形：34.5%↔0.345、万元↔元、—↔至）
- 新增任何数字/引用/URL/DOI
- 把"X 认为 Y"改成"Y 被认为…"（归因漂移）
- 把"可能表明"改成"证明了"（claim 强化）
- 同义替换已登记术语
- 改表格、公式、参考文献、标题、图表编号

## 中英差异速记

- 中文：长短句交替是自然感的主要来源；"的"链过长要拆；主语可适当省略。
- 英文：句长方差 + 开句方式多样化；避免 every paragraph starts the same way。
